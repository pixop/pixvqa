# PU21 Metrics for HDR Video

PixVQA provides `pu21-psnr`, `pu21-ssim`, and `pu21-msssim` for **PQ and HLG** video. They compare display-light values after perceptually uniform (PU21) encoding, unlike conventional PSNR/SSIM on stored YUV codes.

## Usage

For **PQ (HDR10)**:

```bash
./bin/pixvqa --metrics pu21-psnr,pu21-ssim,pu21-msssim \
  --hdr-transfer pq -r reference.yuv -t distorted.yuv \
  -s 1920x1080 -f 420p:10
```

For **HLG**:

```bash
./bin/pixvqa --metrics pu21-psnr,pu21-msssim \
  --hdr-transfer hlg -r reference.yuv -t distorted.yuv \
  -s 1920x1080 -f 420p:10
```

Specify the correct primaries, matrix, range and transfer if compressed metadata is absent or inaccurate. PQ/HLG defaults are BT.2020 primaries, BT.2020 non-constant-luminance matrix and limited range; raw input requires correct declarations. BT.2020 **constant luminance** is supported by PU21 when explicitly selected with `--hdr-matrix bt2020c`; do not relabel CL-coded samples as NCL. This is not supported by bundled HDR VMAF or CVVDP.

## Display settings

- **PQ:** absolute ST 2084 luminance; `--hdr-peak-nits` optionally clips the evaluation display peak (default: no additional clipping).
- **HLG:** default 1000 cd/m² peak, 0 cd/m² black and system gamma 1.2. Override with `--hdr-peak-nits`, `--hdr-black-nits` or `--hdr-hlg-gamma` as needed.
- Chroma reconstruction defaults to left chroma location and bilinear upsampling; override with `--hdr-chroma-loc` and `--hdr-chroma-up`.

Use `./bin/pixvqa --help-hdr` for valid values and per-input overrides (`--ref-hdr-*` / `--dist-hdr-*`).

## Output

PU21-PSNR reports R/G/B components and an aggregate PSNR from pooled component MSE. PU21-SSIM and PU21-MS-SSIM report luminance similarity. These scores are **not interchangeable** with sample-domain PSNR/SSIM. Enable optional temporal [QCS](QCS.md) with `--qcs`.
